# 智能提醒 App — 界面与小组件设计文档（极简版）

> 版本：v2.0 极简版 | 2026-05-06
> 设计理念：**去掉一切装饰，只留信息本身**
> 关联文档：`remind-app-scenarios.md` · `remind-app-feedback.md` · `remind-app-onboarding.md`

---

## 一、设计理念

### 1.1 极简三原则

| 原则 | 含义 | 做法 |
|------|------|------|
| **只做一件事** | App 只干提醒这件事 | 不做天气App、不做日历App、不做运动App，只做"提醒" |
| **零装饰** | 每个像素都在传递信息 | 无插画、无渐变背景、无粒子动画、无装饰色块 |
| **退出感** | 用完即走，不留恋 | 不做信息瀑布流，不做得刷，不做社交功能 |

### 1.2 设计规范

**配色：**

```
浅色模式：
  背景：#FFFFFF（纯白）
  卡片/分割：#F5F5F5（极浅灰，几乎看不见）
  主文字：#1D1D1F（近黑）
  次文字：#86868B（灰）
  强调色：#FF6B35（温暖橙，仅用于关键交互）

深色模式：
  背景：#000000（纯黑，非深灰）
  卡片/分割：#1C1C1E
  主文字：#F5F5F7（近白）
  次文字：#86868B（灰）
  强调色：#FF6B35（不变）

状态色（仅在反馈场景使用，不用作装饰）：
  有用：#34C759（系统绿）
  不需要：#FF3B30（系统红）
```

**字体：**

```
标题：SF Pro Display Medium（中等粗，不是 Bold）
正文：SF Pro Text Regular（常规）
数据/数字：SF Pro Text Medium
Live Activity：SF Pro Rounded Regular
```

**间距：**

```
页面边距：20pt（标准）/ 16pt（小屏）
卡片间距：12pt
卡片内边距：16pt
文字行高：1.5
```

**圆角：**

```
统一 12pt，不做大小圆角混搭
```

**阴影：**

```
无。用 1pt 分割线代替阴影。
```

## 二、App 页面设计

### 总共 2 个页面 + 1 个 Modal

```
[提醒流]  [设置]

Modal：点击某条提醒后弹出半屏操作面板
```

---

### 2.1 提醒流（Feed）— 唯一的主页

**目标：** 所有提醒按时间线展示，像对话记录一样自然

```
┌─────────────────────────────────────┐

│─────────────────────────────────────│
│                                     │
│  今天                               │
│                                     │
│  ┌─────────────────────────────┐    │
│  │  🌧️  08:15                  │    │
│  │                             │    │
│  │  下午有雨，带伞出门          │    │
│  │                             │    │
│  │              ✅             │    │
│  └─────────────────────────────┘    │
│                                     │
│  ┌─────────────────────────────┐    │
│  │  ☀️  07:00                  │    │
│  │                             │    │
│  │  早上好，今天周三            │    │
│  │                             │    │
│  │              👍             │    │
│  └─────────────────────────────┘    │
│                                     │
│  昨天                               │
│                                     │
│  ┌─────────────────────────────┐    │
│  │  📦  18:30                  │    │
│  │                             │    │
│  │  快递到了，记得去取          │    │
│  │                             │    │
│  │              ⏸              │    │
│  └─────────────────────────────┘    │
│                                     │
│  ┌─────────────────────────────┐    │
│  │  🌧️  07:30                  │    │
│  │                             │    │
│  │  今天有雨，带伞出门          │    │
│  │                             │    │
│  │              👍             │    │
│  └─────────────────────────────┘    │
│                                     │
│                                     │
│─────────────────────────────────────│
│  [  提醒  ]         [ ⚙ 设置 ]     │
└─────────────────────────────────────┘
```

**设计规则：**

| 元素 | 规则 |
|------|------|
| 列表形式 | 纯列表，每条一个卡片，时间倒序 |
| 卡片内容 | 只有三行：图标+时间 / 提醒文案 / 反馈状态 |
| 分组 | 按天分组（今天/昨天/更早），分组标题用极浅灰小字 |
| 日期分隔 | 用文字"今天""昨天""5月4日"分隔，不用横线 |
| 反馈状态 | 右下角小图标：✅ 有用 / 👍 正面 / ⏸ 忽略 / ❌ 不需要 / 无标记 |
| 点击行为 | 点击卡片 → 弹出半屏操作面板（不跳转新页面） |
| 空状态 | "还没有收到提醒，稍等一会儿" |
| 滑动 | 左滑→删除该条记录；不做右滑 |

**卡片极简规则：**
- 不显示"推送原因"
- 不显示"AI 决策逻辑"
- 不显示标签分类
- 不显示天气数据、温度、AQI
- 信息密度极低，一屏最多 4-5 条

### 2.2 半屏操作面板（Modal）— 点击卡片后弹出

不跳转新页面，从底部弹出半屏面板：

```
┌─────────────────────────────────────┐
│                                     │
│  （背景模糊，提醒流隐约可见）         │
│                                     │
│  ──────── (拖拽指示条) ────────     │
│                                     │
│  🌧️  下午有雨，带伞出门             │
│  今天 08:15                         │
│                                     │
│  ──────────────────────────────────│
│                                     │
│  有用吗？                           │
│  [👍 有用]      [👎 不需要]         │
│                                     │
│  ──────────────────────────────────│
│                                     │
│  以后这类提醒                       │
│  推送频率          正常        >    │
│  [暂时不推这类了]                   │
│                                     │

```

**规则：**
- 半屏高度（不铺满）
- 下拉或点背景关闭
- 不做"推送原因"展示（太复杂，放到设置里可选开启）
- "暂时不推这类了"后跟随一个 Undo 提示条（3秒后消失）

## 三、小组件设计（极简版）

### 3.1 只做 3 种 Widget

砍掉 Large 和 StandBy，只保留用户最需要的：

| 尺寸 | 用途 | 说明 |
|------|------|------|
| Small | 天气+一句话 | 放主屏幕或 Today View |
| Medium | 天气+日程 | Today View 主力 |
| Lock Screen (Inline) | 一句话提醒 | 锁屏底部小条 |

### 3.2 Small Widget

**尺寸：** 155 × 155 pt

```
┌─────────────────┐
│                 │
│   🌧️  22°C     │
│                 │
│   下午有雨      │
│                 │
└─────────────────┘
```

**设计规则：**
- 纯黑文字 + 纯白背景（浅色模式）/ 纯白文字 + 纯黑背景（深色模式）
- 无背景色、无渐变、无装饰
- 图标用 SF Symbols monochrome
- 文案 ≤ 6 字
- 点击 → 打开 App 提醒流

### 3.3 Medium Widget

**尺寸：** 329 × 155 pt

```
┌─────────────────────────────────────┐
│                                     │
│  🌧️  22°C 多云        📅  今日 3件 │
│  下午有雨             10:00 产品评审│
│                       14:00 需求评审│
│                       17:00 健身   │
│                                     │
└─────────────────────────────────────┘
```

**设计规则：**
- 左侧天气，右侧日程，用竖线分隔
- 无日程时右侧显示最近一条提醒
- 纯文字，无进度条，无颜色装饰
- 文字大小：主信息 15pt Medium，次信息 13pt Regular

### 3.4 Lock Screen Widget

**Inline（时间下方小条）：**

```
        09:32
  🌧️ 22°C  带伞出门
```

- 系统字体，极简
- 不做 Circular 和 Rectangular（信息太多，不够极简）

## 四、Live Activity 设计（极简版）

### 4.1 核心原则

**Live Activity 是整个 App 的灵魂，但设计要极简。**

- 不用天气渐变背景
- 不用天气插画/动画
- 不用进度条
- 纯文字 + 系统图标

### 4.2 紧凑布局（默认）

```
┌─────────────────────────────────────┐
│  🌧️ 下午有雨，带伞出门    22°C      │
└─────────────────────────────────────┘
```

**就这么简单。一行信息，一个图标，一个温度。**

### 4.3 展开布局（灵动岛长按）

```
┌─────────────────────────────────────┐
│                                     │
│  🌧️  多云转雨                       │
│                                     │
│  22°C  |  降水 85%  |  风力 3级     │
│                                     │
│  14:00 - 18:00 有中雨               │
│                                     │
│  [换一个]                [关闭]      │
└─────────────────────────────────────┘
```

### 4.4 不同内容类型的 Live Activity

全部统一格式：**图标 + 一句话 + 可选数据**

| 类型 | 紧凑 | 展开额外内容 |
|------|------|------------|
| 天气 | 🌧️ 下午有雨，带伞出门 22°C | 详细降水/温度/风力 |
| 会议 | 📋 产品评审 还剩15分钟 | 参会人 + 线上链接 |
| 紧急天气 | ⚠️ 暴雨预警 | 详细预警 + 建议 |
| 药品 | 💊 该吃降压药了 | 剂量 + 下次时间 |
| 问候 | ☀️ 早上好，今天周三 | —（不展开） |

### 4.5 切换逻辑（同前版，不变）

```
默认 → 天气
有紧急天气 → 替换
有会议15min内 → 替换
有药品到时间 → 替换
用户点"换一个" → 队列下一条
用户点"关闭" → 销毁，不自动恢复
```

### 4.6 动效

```
内容切换：交叉淡入淡出 0.3s（无弹跳、无缩放）
展开/收起：iOS 系统默认（不自定义）
关闭：iOS 系统默认
```

## 五、通知设计（极简版）

### 5.1 标准通知

```
┌─────────────────────────────────────┐
│  智能提醒                    刚刚    │
│  🌧️ 下午有雨，带伞出门              │
│                                     │
│  有用    不需要                      │
└─────────────────────────────────────┘
```

### 5.2 可执行通知

```
┌─────────────────────────────────────┐
│  智能提醒                    刚刚    │
│  💊 该吃降压药了                    │
│                                     │
│  已吃    稍后                        │
└─────────────────────────────────────┘
```

### 5.3 设计规则

| 规则 | 说明 |
|------|------|
| 标题 | 固定"智能提醒"，不动态变化 |
| 正文 | ≤ 20 字，超过截断 |
| 按钮 | 最多 2 个，文字 ≤ 4 字 |
| 不用富媒体 | 不带图片、不带视频 |
| App 图标 | 不用自定义大图标，用系统默认小图标 |
| 通知分组 | 所有提醒归到一个组，按时间倒序 |

### 5.4 通知音效

```
标准：轻柔短促的"叮"（0.3s）
紧急：两声短"叮叮"（0.5s）
静默：无声音，无震动（饮水/久坐类完全静默）
```

## 六、动效规范（极简版）

**原则：能不做就不做。**

| 场景 | 动效 | 时长 |
|------|------|------|
| 页面切换 | 系统默认 push/pop | 系统默认 |
| Modal 弹出 | 系统默认 sheet | 系统默认 |
| 卡片点击 | scale(0.97) → 1.0 | 0.1s |
| Toggle 切换 | 系统默认 | 系统默认 |
| Live Activity 切换 | 交叉淡入淡出 | 0.3s |
| 新提醒到达 | 列表顶部插入，系统默认动画 | 系统默认 |
| 反馈按钮点击 | 按钮缩放 0.9 → 1.0 | 0.15s |

**不做：**
- ❌ 天气粒子动画
- ❌ 背景渐变切换动画
- ❌ 数字滚动动画
- ❌ 进度条填充动画
- ❌ 弹簧动效
- ❌ 转场自定义动画

## 八、与 v1 版的主要差异

| 维度 | v1（原版） | v2（极简版） |
|------|----------|-----------|
| 页面数 | 5 个（首页/历史/设置/详情/月报） | 2 个（提醒流/设置）+ 1 Modal |
| 首页布局 | 天气卡片+日程卡片+历史卡片拼盘 | 纯时间线列表 |
| 卡片风格 | 圆角大卡片+阴影+渐变 | 极简纯文字卡片+分割线 |
| 天气展示 | 大插画+动态粒子+背景渐变 | 一行文字 |
| Widget | 5 种（Small/Medium/Large/Lock/StandBy） | 3 种（Small/Medium/Lock Inline） |
| Live Activity | 渐变背景+多行信息+多个按钮 | 一行文字+一个图标 |
| 通知 | 标题动态+富媒体+3个按钮 | 固定标题+纯文字+2个按钮 |
| 动效 | 自定义转场+粒子+弹簧+滚动 | 仅用系统默认动效 |
| 月报 | 独立页面 | 移除（V2+考虑加回） |
| AI 洞察 | 独立卡片 | 移除（V2+考虑加回） |
